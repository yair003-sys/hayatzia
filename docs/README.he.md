# היציע: מה בונים ואיך (בעברית פשוטה)

## למה עוברים
האפליקציה היום היא קובץ אחד גדול. היא עובדת, אבל קשה להגדיל אותה, לבדוק אותה ולהוסיף לה דברים בלי לשבור משהו אחר. בונים אותה מחדש על בסיס מקצועי שמתאים לעשרות אלפי אוהדים.

## ממה בנויה הגרסה החדשה
- **Next.js**: הבסיס שעליו בנויה האפליקציה. זה מה שמשתמשות בו חברות גדולות, והוא מהיר מאוד.
- **TypeScript**: שפת תכנות שתופסת טעויות לפני שהן מגיעות לאוהדים.
- **Tailwind**: שיטה מסודרת לעיצוב, כך שכל המסכים נראים אחידים.
- **Supabase**: השרת ומסד הנתונים החדשים. מקום אחד שמחזיק את הנתונים, ההתחברות, הצ'אט בזמן אמת, ואחסון לתמונות ולסרטונים, כולל סרטונים בכיכר.
- **Vercel**: איפה שהאתר החדש יושב באינטרנט. מהיר בכל העולם.

## שלוש סביבות נפרדות
- **מקומית**: אצלי, לבדיקות. נתונים מדומים בלבד.
- **בדיקות**: אתר בדיקות פרטי שרק אתה רואה, עם שרת בדיקות נפרד.
- **אמיתית**: האתר שהאוהדים משתמשים בו. אף בדיקה לא נוגעת בו.

## השלבים
0. בסיס: מסמכים, שלד האפליקציה, עיצוב (עכשיו).
1. ליבה: התחברות, נעילת קבוצה, משחקים וטבלה.
2. קהילה: צ'אט קבוצה, חדרי משחק, הכיכר, תמונות, דירוג שחקנים.
3. פרטיות ובטיחות: הודעות מוצפנות, כניסה בטלפון, דיווחים.
4. צמיחה: נסיעות, אירועים, שוק, התקנה כאפליקציה והתראות.
5. מעבר: האתר הישן מפנה לחדש.

האתר הנוכחי ממשיך לעבוד כרגיל עד שהחדש מוכן.
