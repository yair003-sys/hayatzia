# תשלומים לאירופה — Stripe Connect מול Mollie, ושאלות לעו"ד

**תאריך:** 2026-10-28 · עזר-החלטה ליאיר. לא קוד — מסמך בלבד. מספרים לאימות מול הספק לפני חתימה.

## מה אנחנו צריכים מהספק (הדרישות שלנו)
1. **פיצול שוק (marketplace split) לא-משמורתי** — הכסף מגיע ישירות למוטב, onefan לא מחזיקה אותו, והעמלה שלנו נגזרת אוטומטית.
2. **אימות מוטב (KYC/onboarding)** שהספק מבצע — לא אנחנו.
3. **כיסוי אירופה רחב** + payout למדינות היעד.
4. **רב-מטבעי (יורו)**, SEPA + אמצעי תשלום מקומיים (iDEAL, Bancontact, SOFORT וכו').
5. **SCA/3DS2** (PSD2) מובנה.
6. **דף תשלום מתארח** — לעולם לא נוגעים בכרטיס.

## השוואה

| נושא | Stripe Connect | Mollie (Connect) |
|---|---|---|
| כיסוי אירופה | מצוין, כל האיחוד + מעבר לו | מצוין, ממוקד-אירופה |
| פיצול שוק לא-משמורתי | כן (destination charges + application fee) — סטנדרט הזהב | כן (Mollie Connect, "split payments") |
| אימות מוטב (KYC) | הספק מבצע (Express/Standard accounts) | הספק מבצע |
| אמצעי תשלום מקומיים | הכי רחב | חזק מאוד באירופה (iDEAL וכו') |
| רב-מטבעי + SEPA | כן | כן |
| SCA/3DS2 | מובנה | מובנה |
| תיעוד למפתחים | הכי טוב בתעשייה | טוב ופשוט |
| תמחור (לאימות!) | ~1.5% + €0.25 לכרטיס EEA; עמלות Connect/payout נוספות | לרוב קבוע לעסקה (~€0.25–0.35) + אחוז נמוך; SEPA זול |
| מתי עדיף | היקף גדול, הכי גמיש, הכי הרבה תכונות | פשטות, שקיפות מחיר, אירופה-first |

**המלצתי:** שניהם מתאימים ולא דורשים ישות אמריקאית. אם היעד אירופה-first ורוצים פשטות ושקיפות מחיר — **Mollie** נקודת פתיחה מצוינת. אם רוצים את המקסימום של גמישות/תכונות ותכנון לגדול הרבה — **Stripe Connect**. לא ננעל עכשיו: המתאם (adapter) בקוד מאפשר להתחיל עם אחד ולהחליף.

## התלוי-בכול: היכן onefan מתאגדת
ישות הפלטפורמה (מדינת הרישום) קובעת לאיזה ספק מתחברים ולאן הכסף זורם. זו החלטה של יאיר + עו"ד + רו"ח, קשורה לפתיחת החברה (משימה 8). אין טעם לחתום על ספק לפני שמחליטים את זה.

## שאלות לעו"ד (לפני כל כסף אמיתי)
1. **ישות הפלטפורמה:** באיזו מדינה כדאי לרשום את onefan לפעילות תשלומים באירופה? (מס, רישוי, payout).
2. **מהות הכסף לכל מדינת יעד:** "מימון-מטרה/רכישה קבוצתית" מול "תרומה" — מה הרגולציה בכל מדינה, והאם צריך מעמד מיוחד?
3. **תפקיד הפלטפורמה:** כל עוד לא-משמורתיים — האם באמת נמנעים מרישיון PSP/EMI בכל מדינת יעד?
4. **מע"מ/חשבונית על העמלה** שלנו ברחבי האיחוד (OSS?).
5. **הגנת הצרכן והחזרים** — נוסח מדיניות תקף לאיחוד.
6. **קטינים** — תרומה/פתיחת קמפיין, לפי כל מדינה.
7. **GDPR** — הסכם עיבוד נתונים (DPA) מול הספק, ומה נשמר אצלנו.
8. **באילו מדינות משיקים ראשון** (צר ומדויק עדיף על "כל אירופה" ביום הראשון).

## מה כבר מוכן בקוד (28.10)
- מודל הכסף **רב-מטבעי** (יורו + שקל + USD/GBP), סכומים ב-minor units, תצוגה לפי מטבע.
- המתאם (adapter) לספק — מימוש מדומה בלבד עד בחירת ספק; אי אפשר לחייב כסף אמיתי.
- הכל מאחורי מתג כבוי.
