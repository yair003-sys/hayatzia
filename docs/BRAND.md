# onefan brand (owner's brand guide, 2026-10-12)

The new app is called **onefan** (lowercase wordmark, Inter ExtraBold, letter-spacing -0.02em). The legacy app keeps its old name until cutover.

| Role | Colour | Where |
|---|---|---|
| Deep Stadium Blue | `#003399` | logo, headers |
| Electric Blue | `#0066FF` | `--color-accent`: buttons, focus, highlights |
| Pitch Neon Green | `#00FF66` | `--color-ok`: calls to action, badges, good news |
| Night | `#0A0E1A` | `--color-canvas`, theme colour |
| Soft Gray | `#A0AAB8` | `--color-muted` |

Club pages still use each club's own colours (`teamAccent`).

## Logo and icons
- Source: `apps/web/public/icons/logo.svg` (owner's 100×100 design; the blue "1" brightened slightly so it reads at small sizes, owner approved).
- All PNG icons (192, 512, maskable 512 with the mark inside the safe zone, Apple 180, favicon 32) are generated by `apps/web/scripts/make-icons.py <out-dir>` with the bundled Chromium. Edit the SVG inside the script, re-run, copy the PNGs to `public/icons/`.

## Naming in the app
- The app name and the home tab are "onefan" (owner: drop the word "היציע").
- Hero: "האוהדים של <club>". Stand songs: "שירי הקהל".
