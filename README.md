# היציע

קהילת אוהדי ליגת העל: יציע פרטי לכל קבוצה, וכיכר משותפת לכל הליגה.

## איך זה עובד
- `index.html`: האפליקציה עצמה. מתפרסמת אוטומטית ב-GitHub Pages.
- `scripts/update.mjs`: מושך נתונים מ-API-Football (משחקים, תוצאות, טבלה, הרכבים ואירועים) ושומר אותם בתיקייה `data/`.
- `.github/workflows/update.yml`: מריץ את העדכון כל 10 דקות ומפרסם מחדש כשמשהו השתנה.

## הגדרות
- סוד `API_FOOTBALL_KEY` (Settings → Secrets and variables → Actions): מפתח ה-API.
- משתנה `SEASON` (אופציונלי): העונה. ברירת המחדל היא `2024`, כי זו העונה האחרונה שזמינה במסלול החינמי. כשעוברים למסלול בתשלום, משנים ל-`2026`.

## תקציב פניות
המסלול החינמי מאפשר 100 פניות ביום. הסקריפט עוצר ב-90:
- רשימת המשחקים מתעדכנת כל 10 דקות רק סביב משחקים, ובשאר הזמן כל 3 שעות.
- הטבלה מתעדכנת כל 6 שעות, או מיד אחרי שמשחק נגמר.
- הרכבים ואירועים: עד 2 משחקים בכל הרצה (2 פניות למשחק).
